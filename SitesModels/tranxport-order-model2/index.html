Preguntas frecuentes

¿Necesitas ayuda?

¿Dónde encuentro mi código de rastreo?
Te lo enviamos por WhatsApp cuando confirmamos tu servicio. Siempre inicia con TRX- seguido de números, por ejemplo TRX-001.
¿Puedo buscar sin el código?
Sí. Escribe el nombre del cliente o negocio tal como lo registraste (ej: “Farmacia La Vega”) y el sistema lo buscará.
¿Cuánto tarda un envío?
La mayoría de envíos entre nuestros 5 municipios se entregan el mismo día. Si tu pedido lleva más de 24h en “Pendiente”, escríbenos por WhatsApp.
Dice “Pedido no encontrado”, ¿qué hago?
Verifica mayúsculas, guiones y espacios. Si el error continúa, contáctanos por WhatsApp con tu nombre y fecha del envío y lo resolvemos.

Zona del fundador · guía técnica

Pon tu rastreador en línea en 10 minutos

Sigue estos pasos una sola vez. No necesitas saber programar: es copiar, pegar y arrastrar un archivo.

A Devuelve JSON desde Apps Script

  1. 1Abre tu Google Sheet de pedidos → Extensiones → Apps Script.
  2. 2Borra el código actual y pega el código de abajo (botón Copiar).
  3. 3Pulsa Implementar → Nueva implementación → Aplicación web.
  4. 4En “Ejecutar como”: Yo. En acceso: Cualquier persona. Implementar y autoriza.
  5. 5Copia la URL que termina en /exec y pégala en este archivo donde dice API_URL.
Code.gs — copiar y pegar 
function doGet(e) {
  // Lee ?q=TRX-001 o ?q=nombre
  var q = "";
  if (e && e.parameter && e.parameter.q) {
    q = e.parameter.q.toString().trim().toLowerCase();
  }
  // Nombre exacto de tu hoja
  var sheet = SpreadsheetApp
    .getActiveSpreadsheet().getSheetByName("Pedidos");
  var rows = sheet.getDataRange().getValues();
  // Fila 1 = encabezados: codigo|cliente|destino|fecha|estado
  var found = null;
  for (var i = 1; i < rows.length; i++) {
    var codigo  = rows[i][0].toString().trim();
    var cliente = rows[i][1].toString().trim();
    if (codigo.toLowerCase() === q ||
        cliente.toLowerCase().indexOf(q) !== -1) {
      found = {
        codigo: codigo,
        cliente: cliente,
        destino: rows[i][2].toString().trim(),
        fecha: rows[i][3].toString().trim(),
        estado: rows[i][4].toString().trim()
      };
      break;
    }
  }
  var out = found || { error: "Pedido no encontrado" };
  return ContentService
    .createTextOutput(JSON.stringify(out))
    .setMimeType(ContentService.MimeType.JSON);
}

B Publícalo gratis en Netlify Drop

  1. 1Guarda esta página como archivo: en tu PC crea una carpeta tranxport y guarda este código como index.html dentro.
  2. 2Entra a app.netlify.com/drop (crea cuenta gratis si no tienes).
  3. 3Arrastra la carpeta completa a la zona que dice “Drag and drop”. Espera 20 segundos.
  4. 4Netlify te dará un enlace como tranxport-rastreo.netlify.app. ¡Ese es tu sitio en vivo!
  5. 5Comparte ese enlace por WhatsApp a tus clientes. Cada vez que edites el index.html, vuelve a arrastrarlo para actualizar.

Truco pro: en Netlify ve a Site settings → Change site name y ponle rastreo-tranxport para un enlace fácil de recordar y compartir.
